# test-designer

## このプロジェクトの目的

テキストで書かれたAPI仕様から、テスト観点（正常系・異常系・境界値）を整理することが目的です。整理には Claude Code のサブエージェントを使います。

## test-designer サブエージェントの役割

渡されたAPI仕様を読み、エンドポイントごとに次の4つを表形式で整理します。

- 正常系: 仕様どおりの入力で、期待どおりに動作することを確認する観点
- 異常系: 不正な入力や想定外の状態で、仕様どおりにエラーとなることを確認する観点
- 境界値: 値の上限・下限やその前後で、正しく動作することを確認する観点
- 仕様で不明な点: 仕様から判断できず、確認が必要な点

ルールは次のとおりです。

- 仕様に書かれている内容だけをもとに観点を出す（推測で補わない）
- テストコードは書かない（観点の整理だけを行う）
- 使えるツールは Read（ファイルの読み取り）だけ

```
└── README.md                             # このファイル
```

## 使い方

1. ターミナルでこのフォルダに移動し、Claude Code を起動します。

   ```sh
   cd /Users/ryota/Documents/ai-dev/test-designer
   claude
   ```

2. （任意）`/agents` と入力し、一覧に `test-designer` が表示されることを確認します。

3. サブエージェントを指定して、API仕様をテキストで貼り付けて依頼します。

   ```
   test-designer サブエージェントを使って、次のAPI仕様のテスト観点を整理してください。

   （ここにAPI仕様を貼り付ける）
   ```

   API仕様の書き方は、`test-viewpoints-sample-user-api.md` の「対象のAPI仕様」を参考にしてください。

4. 結果を残したい場合は、続けて次のように依頼します。

   ```
   結果をMarkdownファイルに保存して
   ```

## 今回のMVPの範囲

- test-designer サブエージェントを定義した（`.claude/agents/test-designer.md`）
- サンプルのAPI仕様（ユーザー管理API: `POST /users`、`GET /users/{id}`）で実行した
- 実行結果をMarkdownファイルに保存した（`test-viewpoints-sample-user-api.md`）
